# RaspberryPuree/UsernameLink
going on from hearing of ducklinks ("a super-simple way of centrally managing the format of URLs"); **RaspberryPuree** for users (markdown link); raspberrypuree '@' ("blowing a raspberry") for the UserName, then creates UsernameLink (in .Markdown format)

## example
`@kaivongcom` could-be--for @[kaivongcom](https://github.com/kaivongcom) `# @[kaivongcom](https://github.com/kaivongcom)` 
This steps over to [Digital Identity](https://kaivongcom.github.io/#digitalIdentityContent); where each service has the RaspberryPuree alongside UsernameLink
